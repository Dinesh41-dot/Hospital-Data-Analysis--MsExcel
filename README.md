# Hospital Dashboard and Data Analysis

## Project Overview
This project focuses on analyzing hospital data to gain meaningful insights into patient admissions, hospital performance, medical conditions, and healthcare operations. An interactive Excel dashboard was developed to present key metrics and trends in an easy-to-understand visual format.

## Project Objectives
- Analyze hospital patient records and healthcare data.
- Understand patient admission and discharge trends.
- Identify patterns in medical conditions and hospital visits.
- Monitor key hospital performance indicators.
- Present insights through an interactive dashboard.

## Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Conditional Formatting
- Slicers and Interactive Filters
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Patient Count
- Total Admissions
- Average Patient Age
- Total Hospital Revenue
- Patient Distribution by Medical Condition
- Patient Distribution by Gender
- Admission and Discharge Analysis

## Data Analysis Performed
1. Cleaned and organized hospital datasets.
2. Analyzed patient demographics and medical conditions.
3. Examined patient admission and discharge patterns.
4. Compared patient distribution across different categories.
5. Created visualizations to identify important healthcare trends.
6. Developed an interactive dashboard using Excel.

## Dashboard Features
- Interactive charts and graphs.
- Patient demographic analysis.
- Medical condition analysis.
- Admission and discharge insights.
- Dynamic filtering using slicers.
- KPI-based performance monitoring.
